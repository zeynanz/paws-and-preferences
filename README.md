Paws & Preferences
Paws & Preferences is a web application that helps users discover what kind of cats they like by swiping through cat photos — inspired by swipe based dating apps, but for kitties 😻

Live Demo
https://zeynanz.github.io/paws-and-preferences/

Features
-Swipe right to like a cat
-Swipe left to dislike a cat
-Desktop friendly Like / Dislike buttons
-Welcome screen with smooth fade-in/out animation
-Progress indicator
-Summary screen showing liked cats
-Restart option without refreshing the page
-Sound & haptic feedback
-Background music (starts after user interaction)
-Mobile-first, responsive design

Tech Stack
-React (Vite)
-JavaScript
-CSS
-Cataas API (Cat images)
-GitHub Pages (Hosting)

How to Run Locally
On Terminal:-
-npm install
-npm run dev
